## Practise this

The transferable skills this project drills — the reason it is in focus:

- `SELECT`, `JOIN` across a foreign key, `GROUP BY`
- Aggregates — `COUNT`, `MIN`, `MAX`, `SUM`, `AVG`
- Filtering an aggregate with `HAVING` rather than `WHERE`
- Deriving a column by slicing a string; multi-column `ORDER BY`

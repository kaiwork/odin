## Practise this

The transferable skills this project drills — the reason it is in focus:

- A dispatcher function that routes to one of several operations
- Holding state across events — first operand, pending operator, second operand
- Edge cases as first-class work: divide by zero, chained operations, consecutive operators, multiple decimals, rounding long results

### If time is short

The skills above are the part worth doing yourself — they are what the
practice questions actually test. The markup, event wiring and styling are
scaffolding. If you are pressed for time, build and test the logic in its
own module first, then hand the UI layer to an AI assistant: describe the
functions you wrote and ask it to wire up the DOM against them.

Keeping logic and DOM in separate modules is what makes that handoff clean
— and it is the same separation that makes the logic testable.

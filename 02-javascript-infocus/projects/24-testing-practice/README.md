## Practise this

The transferable skills this project drills — the reason it is in focus:

- Writing pure functions and testing them — no DOM, no state
- `caesarCipher`: per-character shifting with wrap-around and case preservation (closely mirrors the password-string practice question)
- `analyzeArray`: computing min, max, average and length in one pass (the JavaScript counterpart of a SQL aggregate)
- Naming and covering edge cases before the implementation exists

# The Odin Project — Full Stack JavaScript

Study repo tracking the [Full Stack JavaScript path](https://www.theodinproject.com/paths/full-stack-javascript), plus the
[Foundations](https://www.theodinproject.com/paths/foundations/courses/foundations) prerequisite course as `00-foundations-infocus/`.

Folders suffixed `-infocus` are the current study focus — the courses my
practice questions draw on (fundamentals, JavaScript, SQL). The rest come later.

Inside an `-infocus` course, `notes/` and `projects/` hold the three focus
categories — **problem solving** (JS fluency, state, data structures & algorithms),
**SQL**, and **REST API / data manipulation**; `later/` holds the rest of that
course, kept for when I come back to it. Nothing has been deleted.

Tick a box when you finish an item.

📋 **[Practice questions → curriculum map](sample-questions/README.md)** — the six
questions in `sample-questions/`, mapped to the lessons that teach them.
